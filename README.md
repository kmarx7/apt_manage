# 예그린 수도정산

아파트 수도요금을 2개월마다 세대별로 나눠 고지하는 업무용 웹앱입니다. 현장 검침(아이폰), 정산·고지서 PDF·엑셀(맥)을 한 앱에서 합니다.

## 데이터 원칙

**앱 코드만 인터넷에 올라가고, 데이터는 올라가지 않습니다.**

- 검침값, 금액, 기금 장부, 계좌·회사명은 **쓰는 기기의 브라우저 안(IndexedDB)** 에만 저장됩니다.
- 서버, API, 데이터베이스, 분석 도구, 오류 수집 도구, 외부 CDN·웹폰트를 쓰지 않습니다. Vercel은 정적 파일(HTML/JS/CSS)만 내려 줍니다.
- 한 번 열고 나면 인터넷 없이도 동작합니다(PWA). 비행기 모드에서 검침, 정산, PDF, 엑셀, 백업이 모두 됩니다.
- 기기 사이에는 자동 동기화가 없습니다. **백업 파일(JSON)** 로 옮깁니다(아래 참고).

저장소는 공개입니다. 실제 데이터가 커밋되지 않도록 다음 장치가 있습니다.

| 장치 | 하는 일 |
|---|---|
| `.gitignore` | `_handoff/`, `local-data/`, 엑셀·PDF·zip, `backup-*.json` 제외 |
| pre-commit hook | 커밋할 내용에 실제 계좌·금액·검침값이 있으면 커밋 차단 |
| pre-push hook | 커밋된 파일 전체를 한 번 더 검사 |
| `npm run build` 끝의 `check-no-data` | 빌드 결과물(`dist/`)에 실제 데이터가 있으면 빌드 실패 |

금지 값은 코드에 적혀 있지 않고, **이 맥의 `local-data/`(또는 `_handoff/local-data/`) 파일에서 읽습니다.** 그 파일이 없는 곳(Vercel 빌드 서버, 다른 컴퓨터)에서는 파일 이름 같은 일반 검사만 합니다.

## 개발

Node 22 이상.

```bash
npm install          # git hook도 함께 켜짐 (core.hooksPath=.githooks)
npm run dev          # 개발 서버
npm test             # 테스트
npm run build        # 타입 검사 → 빌드 → check-no-data
npm run preview:vercel   # dist/를 vercel.json 보안 헤더 그대로 띄움 (http://localhost:4174)
npm run check:repo   # 커밋된 파일 전체 실제 데이터 검사
```

### 로컬 전용 테스트

`tests/*.local.test.ts`는 실제 데이터로 엑셀 결과와 1원 단위까지 맞는지 확인합니다. `local-data/excel-fixtures.json`, `local-data/seed-backup.json`이 있을 때만 돌고, 없으면 건너뜁니다. 기대값도 그 파일에서 읽으므로 테스트 코드에 실제 숫자가 없습니다.

## 배포 (Vercel)

1. Vercel에서 이 GitHub 저장소를 Import 합니다. 설정은 `vercel.json`에 있어 따로 고칠 것이 없습니다(Vite, `npm run build`, `dist`).
2. 환경 변수는 필요 없습니다.
3. **배포 후 Vercel 프로젝트 설정에서 꼭 확인하세요.**
   - [ ] **Analytics** 꺼짐 (Project → Analytics)
   - [ ] **Speed Insights** 꺼짐 (Project → Speed Insights)
   - [ ] Log Drains, 외부 Integration 없음
   - [ ] 배포 주소에서 보안 헤더 확인:
     ```bash
     curl -sI https://<배포 주소>/ | grep -iE "content-security|referrer|nosniff"
     ```
4. **네트워크 점검:** 배포 주소를 연 뒤 브라우저 개발자 도구 → Network 탭에서, 입력·저장·PDF·엑셀·백업을 하는 동안 **배포 주소 말고 다른 곳으로 가는 요청이 0건**인지 봅니다.

## 아이폰에 설치

1. 아이폰 **사파리**로 배포 주소를 엽니다.
2. 아래쪽 **공유 버튼 → 홈 화면에 추가**.
3. 이후에는 홈 화면 아이콘으로 엽니다.

> iOS 사파리는 홈 화면에 추가하지 않은 사이트의 저장소를, 오래 열지 않으면 지울 수 있습니다. 꼭 홈 화면에 추가해서 쓰고, 백업 파일을 자주 저장하세요. 설정 화면의 "저장 지속성"에서 상태를 볼 수 있습니다.

처음 설치할 때 한 번은 인터넷이 필요합니다. 그다음부터는 비행기 모드에서도 열립니다.

## 백업 파일로 기기 간 옮기기

**아이폰 → 맥** (현장 검침을 마친 뒤)

1. 아이폰 앱: **설정 → 백업 파일 저장** → 공유 시트가 열리면 **에어드롭 → 맥** 선택.
2. 맥: 받은 파일(`backup-수도정산-YYYYMMDD-HHmm.json`)이 다운로드 폴더에 들어옵니다.
3. 맥 앱: **설정 → 백업 불러오기 → 백업 파일 선택** → 미리보기(회차 수, 세대 수, 내보낸 날짜) 확인 → **덮어쓰기**.

**맥 → 아이폰**도 같은 방법입니다(맥에서 백업 저장 → 에어드롭 → 아이폰 '파일' 앱에 저장 → 아이폰 앱에서 불러오기).

> 불러오기는 **덮어쓰기**입니다. 두 기기에서 동시에 고치지 말고, 한 기기에서 작업을 마치면 백업을 옮긴 뒤 다른 기기에서 이어서 하세요.

회차를 확정하면 앱 위쪽에 "백업 파일을 저장해 두세요" 안내가 뜹니다. 백업하면 사라집니다.

## 처음 쓸 때

- **백업 파일로 시작:** 받은 백업 파일을 불러옵니다.
- **빈 상태로 시작:** 기본 세대 목록(26세대)만 들어갑니다. 첫 회차는 표에서 전월값도 입력하고, **설정**에서 은행·계좌·예금주·회사명을 넣습니다(고지서에 쓰임).

## 한 회차 흐름

1. **+ 새 회차** → 전월값이 지난 회차 당월값으로 채워집니다.
2. 아이폰에서 **한 세대씩 검침**: 당월값 입력 → 저장 → 다음 세대.
3. 맥에서 **정산**: 고지서 총액·총사용량 입력, 단가 방식·추가조정 선택, 필요하면 "손익 0 조정값 적용".
4. **정산 확정** → 금액·누진 구간·발행일이 고정되고 기금 장부에 기록됩니다.
5. **고지서** 보기에서 PDF 저장 또는 바로 인쇄(A4 한 장에 2세대), 정산 칸에서 엑셀 저장.
6. **백업 파일 저장.**

## 폴더

```
src/lib/        계산 엔진(calc.ts), 회차 규칙, 장부, 백업, 고지서·엑셀 내용 (화면과 분리된 순수 함수)
src/db/         IndexedDB 저장소 (Dexie)
src/screens/    대시보드, 고지서, 설정, 최초 실행
src/components/ 공용 화면 조각
tests/          단위 테스트 (가상 데이터) + *.local.test.ts (실제 데이터, 로컬 전용)
scripts/        데이터 검사(check-no-data, check-repo-data), 로컬 서버
.githooks/      pre-commit, pre-push
```
